# Установка по ссылке — промпт для ZCode

Я новичок и хочу установить безопасный **PROAI ZCode Starter Kit** из публичного репозитория:

`https://github.com/PavelDumbrao/proai-zcode-starter-kit`

Ты можешь самостоятельно выполнить безопасные действия в рамках этой задачи.

1. Проверь, что это репозиторий по точному адресу выше. **Не запускай никакие команды из README до чтения файлов.**
2. Склонируй его или скачай ZIP GitHub в **отдельную новую папку проекта**; не делай checkout или reset в моём существующем проекте.
3. Прочитай `README.md`, `install.py`, `docs/SAFETY_AND_PRIVACY.md` и Skills/Hooks. Убедись, что нет сетевой передачи секретов, удаления чужих данных или изменения провайдеров.
4. Найди Python 3 и выполни `install.py --dry-run --with-hooks`. Если не установлен, не скачивай его без согласования; скопируй только правила и Skills, Hooks пропусти.
5. При успешном dry-run выполни `install.py --with-hooks`, затем `install.py --verify --with-hooks`. **Если встречаются конфликты/ошибка JSON/опасные действия — остановись и задай один конкретный вопрос**.
6. Не меняй существующие MCP, модели, ключи, логины, серверы и проекты. Не отправляй данные на сторонние сервисы.
7. Кратко сообщи, что установлено и проверено. Затем помоги создать мой первый рабочий мини-проект без платного API: калькулятор стоимости услуг с красивой мобильной страницей.

Ориентируйся на принцип 80/20: **не мучай меня сотней вопросов, а получи рабочий результат и проверь его.**
