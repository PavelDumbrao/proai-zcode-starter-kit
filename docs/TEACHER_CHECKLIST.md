# Чек-лист преподавателя · 12 октября 2026

**Цель:** чтобы новичок за 10–15 минут разобрался с настройкой и начал делать первый рабочий проект.

1. Покажи уже готовый мини-проект (например, калькулятор услуги) **до** теории.
2. Поясни: AGENTS.md = «должностная инструкция»; Skill = «специализация»; Hook = «автоматическая проверка».
3. Участники скачивают Starter Kit и открывают распакованную папку в ZCode, либо используют GitHub-подход из `prompts/INSTALL_FROM_GITHUB.md`.
4. Попроси ZCode проверить и установить пакет. Ключи моделей никто не выкладывает в чат.
5. Участники создают первый простой сайт/калькулятор, без платных AI-интеграций в самом проекте.
6. Каждый добавляет минимум одно изменение своим запросом, затем проверяет работу.
7. Быстрый созвон с теми, кто застрял: выясняем, установлен ли Python 3, доступен ли ZCode и есть ли собственный доступ к AI-модели.

**Важно:** личные настройки преподавателя, рабочие серверы, Hook-уведомления и готовые API-ключи не раздаются. Набор создан заново и не является точной копией приватного профиля ZCode.
