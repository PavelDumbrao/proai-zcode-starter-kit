# Безопасность и приватность

Этот комплект **создан заново** на основе обезличенных принципов работы ZCode. Он **не содержит** оригинальных пользовательских `config.json`, `.env`, `settings.json`, Telegram, Obsidian, файлов проектов, дампов логов, ключей или MCP-конфигураций.

## Что изменяется при установке

1. Если `~/.zcode/AGENTS.md` отсутствует — создаётся. Если существует — блок с метками `PROAI_STARTER_RULES_BEGIN/END` добавляется в конец, предварительно создаётся backup. Если уже стоит неизменённая официальная версия PROAI v1, её единственный блок безопасно обновляется до v2; пользовательские изменения внутри блока не перезаписываются.
2. Создаются четыре отдельные папки `~/.zcode/skills/proai-*/`, другие Skills не трогаются.
3. При `--with-hooks` создаются два Python-файла в `~/.zcode/hooks/` и добавляются правила в `~/.zcode/cli/config.json`; другие секции JSON сохраняются. До изменений конфигурации создаётся backup.
4. Установка **не запускает** Hooks и не использует сетевые запросы. ZCode сможет запускать их после перезапуска; это зависит от совместимости версии.

**Ограничение:** Hooks фильтруют только часть очевидно опасных команд; они не могут остановить все возможные способы удалить файлы или утечь секретами. Не запускайте код незнакомых людей, не выдавайте ключи и не подтверждайте опасные команды вслепую.

## Проверка

Перед раздачей можно выполнить `python3 -m unittest discover -s tests -v`. Тесты используют временную папку, а не реальные настройки текущего пользователя.

При ошибках установки не копируйте содержимое настоящих `config.json` и `.env` в публичные чаты или GitHub.
