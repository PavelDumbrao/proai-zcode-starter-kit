# 🚀 PROAI ZCode Starter Kit · версия 1.1

**Для новичков: от идеи до первого проекта без знания программирования.**

Безопасная учебная адаптация подхода к настройке ZCode: глобальные инструкции, четыре специальных навыка (Skills) и два лёгких Hook-обработчика. Настройки моделей, API-ключи, MCP-серверы, чаты, приватные файлы и личная инфраструктура в комплект **не входят**.

## Быстрый запуск (3 шага)

1. Скачайте ZIP и **распакуйте** его в папку `proai-zcode-starter-kit`. Откройте эту папку как проект в ZCode.
2. Откройте `prompts/PASTE_INTO_ZCODE.md`, скопируйте промпт в чат ZCode. AI проверит содержимое пакета и среду, покажет план и запустит безопасную установку.
3. После установки попросите: **«Создай простое веб-приложение — калькулятор стоимости моих услуг. Сначала сделай работающий вариант без внешних API, покажи как его открыть, затем добавь 2 улучшения».**

## Зачем версия 1.1: AI-исполнитель для новичка

Глобальные инструкции усилены под работу **без технического бэкграунда**: ZCode общается на простом русском языке, объясняет сложные термины на бытовых примерах, предлагает подходящий путь, сам читает файлы и официальные документы, по возможности ищет в интернете, создаёт и тестирует результат. Для безопасных, обратимых шагов он не просит разрешение каждый раз. Перед тратами, отправкой данных, публичными публикациями и необратимыми действиями — обязательно спрашивает.

**Про «любого человека»:** комплект предназначен для Windows/macOS и не требует знания кода, но не гарантирует установку на абсолютно любом устройстве или без подходящего ZCode и подключённой AI-модели. Наличие Python 3 необходимо для автоматического установщика и Hooks; если его нет — агент может скопировать правила и Skills вручную с разрешения владельца, не подключая Hooks. Версии ZCode могут различаться, поэтому используйте `--dry-run` и `--verify`.

**Для обновления с v1.0:** установщик заменит **только точный неизменённый блок правил PROAI v1** на v1.1, сохранит весь текст пользователя вокруг и создаст backup. Если ученик менял исходный блок — установка остановится без перезаписи, чтобы не потерять его правки. Другие Skills, API-ключи, модельные настройки и MCP не затрагиваются.

## Что ставится

| Компонент | Назначение |
|---|---|
| `~/.zcode/AGENTS.md` | Общие правила: ориентация на результат, 80/20, безопасность и проверка качества |
| `~/.zcode/skills/proai-*/SKILL.md` | 4 навыка для первого проекта, API, дизайна и отладки |
| `~/.zcode/hooks/proai_*.py` | 2 компактных Hook (только если явно включить `--with-hooks`) |
| `~/.zcode/cli/config.json` | Добавляются **только** два Hook в существующие события; остальные секции сохраняются |

## Безопасная установка вручную

В терминале **из распакованной папки**:

```bash
python3 install.py --dry-run --with-hooks
python3 install.py --with-hooks
python3 install.py --verify --with-hooks
```

**Windows:** вместо `python3` используйте `py -3`, если доступен. Если Python не установлен, попросите ZCode скопировать инструкции и Skills вручную, а Hooks **пропустить**, не устанавливая программы без вашего согласия.

- Установщик использует только стандартную библиотеку Python и **ничего не скачивает из интернета**.
- Если уже есть `AGENTS.md`, добавляется только отмеченный блок PROAI; оригинал не переписывается целиком.
- Если существует Skills-файл с таким же именем, но другим содержимым, он **не заменяется**.
- Перед изменением `config.json` или существующего `AGENTS.md` создаётся локальная резервная копия `*.proai-backup-YYYYMMDD-HHMMSS` (вне архива).
- Установщик не читает и не копирует API-ключи в отчёты. Существующий конфиг ZCode обрабатывается только локально.
- При повторном запуске одинаковые инструкции, Skills и Hooks не дублируются.

## Что такое Skills, Hooks и глобальные инструкции?

**Инструкции** объясняют AI, *как* работать. **Skills** — дополнительные сценарии работы для конкретных типов задач. **Hooks** — программные проверки до и после действий. Hooks — лишь дополнительная защита, они **не являются песочницей** и не могут гарантировать безопасность всех команд.

## Первый вечер: что делать

- До 15 минут: знакомство с ZCode и примерами сайтов, приложений, ботов и агентов.
- 10–15 минут: открыть комплект, установить безопасные настройки.
- 35–45 минут: сделать простое приложение, увидеть его в браузере.
- Затем: самостоятельно изменить текст, дизайн и одно действие приложения.

В этом наборе нет платных подписок, токенов и универсального обещания «без API»: подключение внешней модели или стороннего сервиса зависит от доступного способа авторизации у участника.

**Происхождение:** учебная переработка общих инженерных принципов из действующей конфигурации ZCode; никакие частные файлы конфигурации MacBook не копировались в готовый набор.
