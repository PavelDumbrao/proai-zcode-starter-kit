# PROAI First Project

**Когда использовать:** «сделай сайт», «хочу приложение», «у меня идея», «создай калькулятор/квиз/страницу».

1. Прочитай README и структуру текущего проекта. Если проекта нет, начни в новой **отдельной** папке с понятным названием.
2. Сформулируй в одном абзаце: пользователь, задача, обязательные 2–3 действия в приложении.
3. Первая версия — **действительно работающая**, без платных API и логинов, если они не нужны. Например: `index.html`, `styles.css`, `app.js`.
4. Сделай адаптацию под телефон, явное состояние ошибок, понятные надписи и реальные кнопки.
5. Запусти страницу локально доступным способом. Если нужен локальный веб-сервер, сначала используй стандартный установленный инструмент.
6. Сделай одну реальную проверку: ввод → действие → ожидаемый результат. Если инструмент проверки недоступен, честно скажи.
7. Покажи пользователю путь к результату и **три коротких изменения**, которые он может попросить на русском.

**Не делай:** фиктивные кнопки, показные дашборды с выдуманными цифрами, регистрацию/оплату без запроса.
