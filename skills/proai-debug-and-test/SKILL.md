# PROAI Debug and Test

**Когда использовать:** «сломалось», «не открывается», «не работает», «почему ошибка», «исправь».

1. Попроси или прочитай **точный** текст ошибки, команду запуска и ожидаемый результат (если уже доступны — не спрашивай повторно).
2. Сначала повтори ошибку в безопасном локальном режиме. Не начинай с полной переустановки.
3. Изучи не более 3 вероятных причин, опираясь на факты.
4. Исправь минимальную область, не переписывая весь проект.
5. Повтори тот же сценарий. Добавь небольшой тест, если есть смысл.
6. После исправления проверь, что не сломалась предыдущая рабочая функция.
7. Дай отчёт: **причина → исправление → результат проверки → что осталось**.

Запрещено заявлять о тестах, которые не запускались. Без подтверждения — «предполагаю», не «доказано».
