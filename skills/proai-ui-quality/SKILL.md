# PROAI UI Quality

**Когда использовать:** «сделай красиво», «поправь вёрстку», «адаптируй под телефон», «UI/UX».

1. Сначала проверь, что страница работает. Не маскируй сломанную функцию красивым макетом.
2. Единые отступы, читаемые заголовки, понятный первичный призыв к действию и реальные состояния кнопок.
3. Высокий контраст текста на фоне, читаемость на телефоне, размеры кликабельных элементов.
4. Основной сценарий должен помещаться в 1–3 понятных шага.
5. Не вставляй стоковые отзывы, ложные счётчики, вымышленные логотипы клиентов и фиктивные платежи.
6. Проверь ширину 360–390 px и обычный desktop viewport. Если браузер недоступен — отметь это.
7. Кратко перечисли, что изменил и какую проблему это решает.
