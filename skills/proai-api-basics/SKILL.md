# PROAI API Basics

**Когда использовать:** «подключи нейросеть», «через API», «сделай Telegram-бота», «соедини сервисы».

1. Объясни API одной фразой: интерфейс, через который одна программа обращается к другой.
2. Сначала нарисуй цепочку: **пользователь → наше приложение → внешний сервис → ответ**.
3. Проверь официальную документацию **именно нужной версии API**. Не выдумывай название модели, endpoint или бесплатный тариф.
4. Сделай mock-заглушку и проверь пользовательский сценарий прежде, чем подключать реальные внешние сервисы.
5. **Секретные ключи не должны попадать в клиентский JS, Git, чат или скриншоты**; используй безопасное серверное окружение, `.env.example` только как шаблон.
6. Заложи ошибки 401/403, 429, тайм-ауты, непустой ответ, ограничения бюджета и понятный текст ошибки.
7. До любых реальных отправок в Telegram, расходов или создания облачных ресурсов запроси явное разрешение.
8. Проверь подключение безопасным тестом; не называй неподтверждённое «готовым».

Новичок не обязан знать OAuth, webhooks и JSON заранее — объясняй по ходу, только когда это нужно.
